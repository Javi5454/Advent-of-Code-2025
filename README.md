# Advent_of_Code_2025

This repository contains my solutions for [Advent of Code 2025](https://adventofcode.com/2025).

Each day's solution is provided as a separate Rust binary under the `src/bin/` directory, using an input file for that day stored in the `inputs/` folder. For every puzzle, you'll find a dedicated Rust source file (`src/bin/dayNN.rs`) and the corresponding input (`inputs/dayNN.txt`). Both parts of each day's challenge are solved within the same Rust file.

I'm currently learning Rust, so these solutions are part of my learning journey. The code may not always be idiomatic or perfect, but I'm using this project to improve my skills while solving interesting algorithmic puzzles.

I encourage you to try solving the problems yourself! It's fun and rewarding—and even better with friends (you can create a private leaderboard to compete).

My goal is to solve and upload a solution every day, although some days I may be challenged by a particularly tough problem.

## Repository contents

- Input files for each day in the `inputs/` folder, formatted as `.txt`.
- Rust source files for each solution in `src/bin/`.
- Basic tests for each part are included in each Rust file, validating examples for the given day.
- A single `Cargo.toml` file at the root of the project.
